## 一、3D 渲染与相机

### 1. 透视投影会压扁画面边缘的球体
- **现象**：总览构图里太阳呈横椭圆（实测 44×36px，压扁率 0.82 ≈ cos37°）。
- **根因**：参考站用正交投影（球永远正圆），本项目用透视相机复现同构图，太阳位于画面
  最左缘、偏离光轴约 37°，广角边缘畸变必然压扁。
- **解法**：加一块永远面向相机的正圆贴片（带临边昏暗+米粒组织的自制贴图），远看盖住
  压扁的球，按屏幕半径（>130px）淡出露真球。
- **验证**：把贴图投影成球逐像素量宽高比。

### 2. Billboard/贴片定位必须用"当帧"相机
- **现象**：缩放时出现两个错开的太阳（平滑圆片 + 带纹理球体）。
- **根因**：贴片在 `solar.update()` 里用**上一帧**相机定位，而相机更新在其后；缩放中
  相机每帧移动几十个单位，贴片永远慢一帧。
- **解法**：抽出 `syncSunDisc(camera)`，在主循环 `flight.update()`（相机位姿定稿）之后调用；
  偏移量改为沿视线 1.03R，投影同心零视差。

### 3. 辉光类 sprite 必须按出画程度淡出
- **现象**：聚焦木星时画面左侧渗进一团"无源白雾"。
- **根因**：太阳外层辉光（4.6R、加性混合）只按距离调亮度，不判断是否在视野内；
  太阳在画面外 40 单位时辉光仍有 ~320px 半径，从边缘渗入。
- **解法**：用太阳的 NDC 投影判断出画程度（≤1.05 全亮，≥1.5 熄灭），opacity 乘该系数。

### 4. 悬停拾取必须做遮挡剔除
- **现象**：月球特写时，藏在它背后的金星也触发金色锁定环。
- **根因**：拾取只看屏幕投影距离，不判断遮挡。
- **解法**：先收集候选再做剔除——候选中心被"更近且屏幕上更大"的天体圆面盖住（>96%）
  即不可选。

### 5. "纯色球体"感的两个来源与解法
- 贴图本身无特征（天王星/海王星可见光下近乎均匀）→ 保色相的对比增强，勿用逐通道
  `autocontrast`（会把淡色行星拉成"下半黑+上半过曝"或品红假彩）。
- 球体边缘无厚度 → Fresnel 大气壳层 shader（球心透明、边缘发亮，加性混合），
  地球最亮、气巨柔和。

## 二、UI 动效与标签

### 6. 标签"抽搐"的四件套
1. **上下翻转要带死区+冷却**：重叠避让每帧重算，两个靠近的标签会逐帧互相把对方挤到
   另一侧。解法：当前位要"压得更深"（inflate +4）才算冲突，另一侧要"明显更空"
   （inflate −4）才允许翻，再加 480ms 冷却。模拟 300 帧验证翻转 0 次。
2. **尺寸只量一次**：每帧读 `offsetWidth/offsetHeight` 强制同步重排，且字体加载/缩放
   会让框微抖。
3. **显隐阈值加迟滞**：已显示的用更宽的退出阈值（110→118px），隐藏需连续 5 帧冲突。
4. **位置取整到像素**：亚像素定位在缓慢移动时文字发虚发颤。

### 7. CSS 交互动效用独立的 `scale`/`translate` 属性
- 给整行（宽 172px）加 `hover { translate: 3px }` 或 `:active { scale: .955 }`，
  缩放中心在行中央，会把行内**左端的圆点横向推出 ~4px**——"圆心不对齐"就是这么来的。
- 解法：只对圆点本身缩放（transform-origin 在圆心），行不做位移。

### 8. 指针/标记的形态切换全部走透明度过渡
准星隐去、锁定环浮现、瞄准标记替换，三者统一 `opacity` + `cubic-bezier(.22,.68,.24,1)`；
锁定环从 `display` 硬切改为 opacity 淡入淡出后，"指针凭空消失/突然出现"消失。
另注意：**环没画出来的分支必须把准星还回来**（目标占屏 >90px 时不画环）。

### 9. 全局交互反馈的最小集
`:active` 内缩（scale .955）、hover 上浮 1px + 金色微光、`:focus-visible` 金环、
`prefers-reduced-motion` 支持。自定义 `cursor: none` 的项目里，按压反馈是唯一的
"点到了"提示，必须有。

## 三、状态机与过渡动画

### 10. 承载场景状态切换的大过渡必须不可打断
- **现象**：过渡做到一半拖拽，星座无法显示。
- **根因（两层）**：返回方向的过渡**没有中断收尾钩子**（取消飞行后 onDone 永不触发，
  setRange/淡出全停在半路）；模式切换用 `tweens.length = 0` 把未完成补间直接扔掉，
  skyFade/缩放悬在中间值。
- **解法**：
  - `flight.inputLock`：大过渡期间画布 pointerdown/wheel 直接 return；
  - `finishTweens()`：模式切换时把未完成补间**推到终态**并触发回调，不丢半路；
  - `flyTo` 取代旧飞行时同步解锁（否则过渡途中点导航轨 → 新飞行带死锁）；
  - 每条过渡的 onDone 与 onFlightCancel（兜底）共用同一个收尾函数 + 防重入标记。

### 11. "由模式推导"的标志必须用 getter 派生
`dragInvert` 只在 `setFreePitch()` 里赋值，而启动路径 `bootSolar()` 从没调用它 →
**冷启动与逛一圈深空回来后手感相反**，看起来像"版本不统一"。
原则：能从现有状态推导的标志一律 `get xxx() { return ...; }`，绝不单独存副本。

### 12. 惯性/阻尼拖拽的通用手感参数
拖拽系数按弧度/像素给（太阳系 0.0012/0.0011，深空 0.0024），低通滤波记瞬时角速度，
松手滑行并设上限；缩放后 2.2s 内的俯仰联动在拖拽/飞行时跳过。

## 四、天文模型与科普口径

### 13. 简化历表撑不起"事件演出"，要按时间轴合成
- 实测四场月食的**食甚时刻**，简化历表（月球只有平黄经+出差）算出的月心离地影轴
  2.0～8.0 个单位，而本影半径只有 0.33——按真实位置摆，月食根本不会发生。
- 解法：食相按进程参数化（`phase ∈ [-1,1]`，0 = 食甚、±1 = 恰好接触），月球位置随
  进程连续移动；日食距离按"月面角径 = k × 日面角径"从当前日地距反算
  （全食 k=1.06、环食 k=0.90、偏食食甚仍留缺口），示意排布与真实轨道两种布局都成立。
- **验证方法**：脱离渲染器，用纯数学脚本算接触角距 vs 理论值、相位→遮挡率、
  相位→染色强度，逐项断言。

### 14. 比例口径要成文
行星显示半径 `0.0115 × km^0.42`；卫星半径=真实比例（<0.035 取保底可见）、轨道=真实
行星半径倍数（>22 压缩到 22）；月球 22 个地球半径。口径改一次，受影响的影锥/染色/
相机取景全部要跟着重算。

### 15. 科普文案逐条对公开数据
易错模式：**北天/全天**混淆（织女星是全天第五、北天第二）、共振对象写错（拉普拉斯
共振是木卫一/二/三）、单位口径（斯蒂克尼坑 9km 不是 12km；土星环直径 28 万 km）、
"唯一"vs"两颗之一"（金星逆向自转）、探测器时态（贝皮科伦坡 2026-11 入轨）。

## 五、贴图资产管线

### 16. 数据源清单（含实测速度/坑）
| 源 | 内容 | 备注 |
|---|---|---|
| Solar System Scope | 8K 全套行星/月球，CC BY 4.0 | 最快 ~44KB/s；天王/海王/金星云顶官方最高 2K |
| USGS Astrogeology | 全球影像镶嵌（公共领域） | 站点要浏览器 UA；直链 `planetarymaps.usgs.gov/mosaic/<名>.tif` |
| NASA Images API | `images-api.nasa.gov/search` + `images-assets.nasa.gov/image/<id>/<id>~orig.jpg` | 稳定；搜不到的换关键词多试 |
| NASA SVS | LROC 月球 4K tif | 仅 8KB/s 且中途断连——**分块 Range 下载**（1MB/段单独重试）能绕过 |
| Wikimedia Commons | API 被拒，但 `Special:FilePath` 直链可用 | 行星地图类：`Io_map_JPL.jpg` 等 |

### 17. 贴图验收方法：投影成球看，不看平面图
写一个 30 行的正交投影脚本把每张贴图贴到球上再检查（上下颠倒/镜像/接缝/黑极冠
一览无余）；再用项目真实光照+ACES 模拟 180px 观感，判断"是不是纯色"。
逐通道 `autocontrast` 是本会话最大的贴图事故源（毁掉天王星/海王星/金星三张）。

### 18. 无柱面底图的天体别硬造
天卫三/四、火卫二、海卫一只有极地投影或带夜面的圆盘照。圆盘反解会出现黑极冠和
镜像拉伸，比不用还糟。方案：同类天体的真实影像 + 真实反照率着色（`tint` 字段），
并在 README「素材与授权」注明。火卫一后来拿到了 Mars Express 5760×2880 镶嵌，
立刻替换。

### 19. 贴图引用做存在性检查
删旧贴图后，残留引用会 404 并**静默退回程序生成的灰球**（天卫三踩过）。
脚本：正则扫 `tex:`/`assets/` 引用 → `os.path.exists` 逐个断言。

### 20. 两档资源、一份代码
`assets/`（网页压缩版）+ `assets/full/`（同名同路径的高清版），
构建时同名覆盖；8K 银河不另存副本，构建时直接引用原图。
CSS 背景图固定读压缩版，否则 8K 会被内联**两遍**（白白多 24MB）。

### 21. 影像授权必须署名
CC BY 4.0（Solar System Scope）写进档案卡"资料来源"和 README；NASA/USGS 公共领域
也注明来源，星座图注明"银河全景裁切 + 依星表自绘连线"。

## 六、单文件离线包（build.mjs）

### 22. 为什么必须单文件
`file://` 下 ES module 请求被拒、本地图片 fetch 被拒、且本地图片会污染画布导致
WebGL 纹理上传失败。解法：esbuild 打成 IIFE + 全部贴图转 data URI 内联 + CSS 内联。

### 23. 巨型 script 会卡死加载动画
62MB 单文件若把 43MB 图片压成**一个** `<script>`，浏览器一口气解析完，主线程被独占，
加载屏 rAF 停摆，进度条卡在个位数。解法：**每个资源一条 `<script>`**，每条结束回调
`__assetTick(i)` 直接写 DOM（不等 rAF），轨道再加一条合成层扫光动画兜底。

### 24. 进度条模型（踩了三次坑的最终形态）
```
真实进度 target（THREE manager / 资产 tick）
下限 floor = 0.86 × (1 − e^(−t/3.5))     ← 指数渐近，绝不能线性（2 秒冲顶后卡死）
goal = max(target, floor)
shown += (goal − shown) × 0.10            ← 平滑趋近
finish 后 → 收尾到 100% 再淡出
```
教训链：一次性设宽度（不动）→ 吸附条件写反（target=0 时每帧吸回 0）→ 线性下限
（先卡后跳）。最终用 **DOM 桩在 Node 里模拟执行**逐帧打印才定位。

### 25. `String.replace` 的 `$&` 坑
压缩后的 JS 里含 `$&`/`$'` 序列，作为**替换字符串**传入时会被当成"插入匹配内容"的
占位符，把原 `<script>` 标签注进 bundle 造成语法错误。处理生成物一律用**函数式替换**
`.replace(re, () => str)`。

## 七、工程与发布

### 26. 版本戳 + 一条命令统一 bump
- 右下角常显 `v207 · 网页版 / 离线版`（9.5px、26% 透明度）：网页版从 `loading-boot.js`
  的 `?v=` 查询串读，离线版由 build.mjs 注入 `window.__BUILD`。
- bump：`perl -pi -e 's/\?v=206/?v=207/g' index.html css/style.css js/*.js`。
- 本会话大量"改了没生效"最终都归结为：旧缓存 / 旧离线副本 / 版本没对上。

### 27. 本地服务器必须带 no-store
`python3 -m http.server` 不发缓存头，Safari 会一直复用旧 index.html（连带旧 JS），
普通刷新无效——"知识标签删了还在"即是此因。`serve.py` 给每个响应加
`Cache-Control: no-store`，启动脚本改用它，根治。

### 28. 双发布路线
- **GitHub Pages**：纯静态站 + `.nojekyll`，银河原图 8K 不进库（.gitignore），整站 ~13MB。
- **离线单文件**：`npm run build`（全尺寸 ~65MB）/ `npm run build:web`（压缩 ~27MB）。
- 交付前交叉验证：bundle 抽出来单独 `node --check`；资产映射逐键确认尺寸/体积。

### 29. API 交叉引用全检（防"一加载就崩"）
脚本对查三组：①UI 需要的 `this.cb.*` 回调 ↔ main 提供的配置；②main 调用的 `ui.*`
方法 ↔ 类定义；③跨模块 import ↔ export。再加 DOM id 引用检查与
"已删 API 残留引用 = 0"扫描。删除功能时（如砍掉知识库）必跑——曾漏删一行
`ui.fillArticles(ARTICLES)` 导致新代码一加载就 ReferenceError。

## 八、调试方法论（本会话反复验证有效）

### 30. DOM 桩 + Node 模拟执行
无头浏览器装不上（Chromium 下载两次超时）时，用极简 DOM 桩把加载动画/拖拽控制器
在 Node 里真跑起来，逐帧打印数值——定位了"进度条吸附归零"（1.4 秒只走 0.35%）这类
纯看代码看不出来的 bug。

### 31. 真实依赖参与的计算测试
拖拽方向、日月食几何这类"符号推容易错"的问题，直接 import 项目里的 three.module.js
和 astro.js 跑投影/求交，用输出判定对错（推了三遍方向仍拿不准，一跑就清楚）。
注意：模块的 `?v=` 查询串先 strip 掉，`from 'three'` 替换成本地绝对路径。

### 32. 截图数值化分析
"圆心不对齐""神秘光晕"都是先放大裁切、再做像素统计（按列找竖线、按行找亮斑、
亮度阈值分割），拿到具体偏差像素数再定位 CSS/几何原因——比目测猜快得多。

### 33. 本机环境坑
- shell 的 `grep` 出现过假阴性/异常输出，关键检查用 **python 重写**。
- 多行 commit message 带特殊字符时用 `git commit -F 文件`。
- 无头浏览器（agent-browser/playwright）Chromium 下载在本机网络反复超时，
  不要反复重试，改走 30 的路线。

## 九、内容生产

### 34. 介绍图必须是真实影像，网络图源不可信
原图 13 张星座图里 11 张是错的（双子座的 NASA 任务徽章、大犬座的建筑、
南十字/天蝎的空间站照片、狮子/大熊的星系图）。最终方案：**从 4K 银河全景按各星座
真实赤经赤纬做球面透视裁切**（1280×720），叠加依星表绘制的星点与连线——背景是
真实天空照片且与场景天球一致；星云卡用 NASA Images API 逐张核验主体。

### 35. 内容密度标准
星云/星座卡 = 简介 + 2 节正文（每节 60–90 字，讲一个具体机制）+ 3 条冷知识 +
数据行。冷知识优先"文化联动"（斯巴鲁车标、七月流火、国旗上的南十字）与
"反直觉事实"（织女星将成为北极星、天狼 B 是白矮星）。
